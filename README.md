# X-Point | الموقع + لوحة التحكم

موقع X-Point مربوط بلوحة تحكم: أي تعديل أو رفع صور من اللوحة بيظهر في الموقع فورًا، وطلبات الفورم بتتخزن وتتعرض في اللوحة.

## التشغيل
```bash
npm install
ADMIN_PASSWORD="كلمة-مرور-قوية" npm start
```
- الموقع: `http://localhost:3000`
- لوحة التحكم: `http://localhost:3000/admin`
- لو ما حطيتش `ADMIN_PASSWORD`، بتتولد كلمة مرور وتظهر في سجل التشغيل أول مرة بس. غيّرها من «الأمان والنسخ الاحتياطي».

## اللي تقدر تتحكم فيه
الإعدادات العامة (الأرقام والروابط والـ SEO) · الصفحة الرئيسية · نقدر نساعدك · الخدمات · العقارات (مع رفع صور) · الحاسبة · ليه X-Point · مسارات الخدمة · آراء العملاء · الأسئلة الشائعة · التواصل · الفوتر · مكتبة الصور · طلبات العملاء (حالة + تصدير CSV) · نسخ احتياطية واسترجاع.

## النشر (لازم استضافة Node.js)
مش هينفع على استضافة ملفات ثابتة فقط. مناسب: Render / Railway / Fly.io / VPS / أي استضافة بتدعم Node 18+ أو Docker.
1. ارفع المشروع (من غير `node_modules`).
2. أمر التشغيل: `npm start`، والمتغيرات: `NODE_ENV=production` و`ADMIN_PASSWORD`.
3. **مهم:** اربط مجلدي `data` و`uploads` بـ Volume دائم، وإلا البيانات والصور بتضيع مع كل إعادة نشر (`DATA_DIR` و`UPLOAD_DIR`).
4. شغّل الموقع على HTTPS. الكوكي بيبقى `Secure` تلقائيًا في production.
5. لو ورا proxy (Nginx/Cloudflare) تأكد إنه بيمرر `X-Forwarded-For`.

Docker: `docker build -t xpoint . && docker run -p 3000:3000 -e ADMIN_PASSWORD=... -v xp-data:/app/data -v xp-up:/app/uploads xpoint`

## الأمان (اللي متطبق)
كلمة المرور متخزنة بـ scrypt · جلسة موقّعة HttpOnly + SameSite=Strict (12 ساعة) · حد لمحاولات الدخول (6 كل 15 دقيقة) وحد لإرسال الفورم · تنضيف كل النصوص من الـ HTML (إجابات الأسئلة الشائعة تقبل `<b>` و`<a>` بس) · رفع صور فقط (JPG/PNG/WEBP/GIF حتى 6MB، بدون SVG) · أسماء ملفات عشوائية · نسخة احتياطية تلقائية قبل كل حفظ (آخر 30).

## ملاحظات
- في إجابات الأسئلة استخدم `{WA}` مكان رقم الواتساب علشان يتحدث تلقائيًا من الإعدادات العامة.
- فورم التواصل بيخزن الطلب في اللوحة وبيفتح واتساب برسالة جاهزة للعميل.
- مستخدم أدمن واحد بكلمة مرور واحدة.
- المحتوى في `data/content.json`، والطلبات في `data/leads.json`.
